# ▇▇ · 记忆层运行规则

> 这一层解决一个具体问题：**新会话的 Aime 不知道你是谁、不知道项目到哪了，每次都要你重讲一遍。**
> 它不是又一个知识库，是**知识库的入口和摘要**。

---

## ▇▇. 为什么原来会失忆（诊断，不是理论）

| 症状 | 真实原因 | 这一层怎么治 |
|---|---|---|
| 新会话不知道你的偏好 | 偏好散在 ▇▇行学习日志和 ▇▇行规则库里，没有一处集中 | 抽成 `01-个人偏好.md`，并把最高频 ▇▇条上提到 `MEMORY.md` |
| 记得业务、不记得项目 | 仓库结构是按"业务实体"建的（机构/达人/客户），**没有"项目"这个维度** | 新增 `03-项目细节.md`，一个项目一张卡，跨业务与非业务 |
| 读了也用不上 | AIME.md 要求"先读四份记忆文件" = ▇▇行，会话开头就吃满预算，只能选择性读 | `MEMORY.md` 硬上限 ▇▇行，其余按指针**按需下钻** |
| Mac 一断连就完全断供 | 仓库只有本地一份，挂载掉了 Aime 什么都读不到（2026-09-13 实际发生两次） | `MEMORY.md` + 五册**双写云端镜像** |
| 同一个坑踩第二遍 | 踩坑记录混在规则库正文里，动手前不会专门去翻 | `04-常错清单.md` 独立成册，写代码/改数字前必看 |

## ▇▇. 分类标准（写入前先判断落哪一类，别混）

| 分库 | 装什么 | 判断句 | 编号 |
|---|---|---|---|
| `01-个人偏好.md` | 她要什么形态、什么语气、什么交付物、什么雷区 | "她**喜欢/讨厌**……" | U-xx |
| `02-决策习惯.md` | 她**怎么做选择**的模式 | "遇到 X 她通常会……" | D-xx |
| `03-项目细节.md` | 每个项目是什么、到哪一步、卡在谁、关键数字与地址 | "这件事现在到哪了" | J-xx |
| `04-常错清单.md` | **我**犯过的错和防复发动作 | "我上次因为……搞错了" | E-xx |

⚠️ **和 `_系统/` 的分工**：`_系统/` 装**业务知识**（口径怎么算、业务规则 if-then）；`_记忆/` 装**关于人和项目的记忆**。
判断句：这条知识换个销售来用还成立吗？成立 → 进 `_系统/`；只对本人成立 → 进 `_记忆/`。

## ▇▇. 写入规则（防止这一层变成第二个 ▇▇行日志）

▇▇. **每条必须挂事件锚**：日期 + 编号（Q-xxx / P-xx / R-xxx）+ 她的原话片段。没有锚的不许写进来，进 `_系统/待复核队列.md`（R-526）。
▇▇. **一条只说一件事**，超过 ▇▇行的拆开。
▇▇. **容量硬闸**：`MEMORY.md` ≤▇▇行；`▇▇`/`▇▇`/`▇▇` 各 ≤▇▇行；`▇▇` 每张项目卡 ≤▇▇行。**超了就必须合并或降级，不许扩容。**
▇▇. **只写"下次还会用到"的**。一次性的执行细节留在原文件里，这里只留能复用的判断。
▇▇. **冲突不静默覆盖**：新条目和老条目矛盾时，两条都留，标 `⚠️冲突`，挂进待复核让她裁（R-518 / R-523）。
▇▇. **新编号先查最大号**再 +▇▇（E-01 就是撞号踩的）。

## ▇▇. 每日整理（每天 10:00，和每日三问、每日简报一起，≤▇▇ 分钟）

固定五步，缺一步算没做：

▇▇. **取料**：昨天的会话 + 工作台收件箱（`GET /api/v1/fb?fmt=md`）+ 昨天改过的仓库文件。
▇▇. **抽取**：最多 ▇▇条进分库。抽不出就写"无"，**不许为了凑数把执行日志当认知**。
▇▇. **改状态**：更新 `MEMORY.md` 第 ▇▇ 节"现在到哪 / 卡在谁"和第 ▇▇ 节"等她定的"。这两节是唯一每天必改的。
▇▇. **压容**：如果 `MEMORY.md` 超了 ▇▇行，先删第 ▇▇ 节里已完成的项目行，再合并第 ▇▇ 节的近义条目。
▇▇. **同步 + 留痕**：写一行进 `05-记忆变更日志.md`，并推云端镜像。

> ⚠️ 10:00 复盘的是**昨天**，提问一律用"昨天"（AIME.md §0-0）。

## ▇▇. 每周复盘（每周五 10:00，≤▇▇ 分钟）

▇▇. **去重**：同一意思两条 → 合并，保留事件锚更硬的那条。
▇▇. **降级**：▇▇ 天没被命中过的偏好/习惯，标 `🕓观察中`；再 ▇▇ 天没命中，移到文件末尾"已退役"区，不删。
▇▇. **冲突扫描**：同一主题存在方向相反的两条 → 挂 `⚠️冲突` 进待复核，**不自动按时间覆盖**（R-518）。
▇▇. **项目卡体检**：每张卡问三句——现在到哪？卡在谁？她上次说的下一步做了吗？没做的回挂任务队列。
▇▇. **重算 MEMORY.md**：项目状态、等她定的、行数，全部重算一遍，版本号 +▇▇。
▇▇. **交一份 ▇▇行摘要给她**：这周记住了什么新的 / 忘掉了什么过期的 / 哪里发现了冲突。
