## 四条区级铁律（锁死，落地时不许违反）

| 区 | 硬约束 |
|---|---|
| Ⅰ 驾驶舱全景 | ⛔ 不放具体业务数字（业绩、客户、达人、商机数）。只放系统级"状态、调度、结果梳理、反馈"。 |
| Ⅱ 认知与学习 | ⛔ 不做已有记忆内容的复述，⛔ 不呈现具体业务信息。只做"向外看的思维原料 + 系统认知能力迭代"。 |
| Ⅲ 高阶交互系统 | ⛔ 不呈现具体内容与具体业务信息。只做"多模块调度、技能库、系统自运行反馈"。 |
| Ⅳ 业务工作区 | 业绩金额只在这一区。⛔ 不做业务简单汇总，必须是"进阶思考反推 + 自运行工作能力 + 业务助力自主判断"。 |

## Ⅰ 驾驶舱全景（▇▇ 模块）

### ▇▇ 工作台业务模块总览 · `m_over`

- **定位**：一屏看清整个工作台 ▇▇ 区 ▇▇ 模块的健康度：每模块最近更新时间、五格填充度、是否有阻塞、是否被外部引用。
- **呈现要求**：▇▇ 区栅格 + 每模块一张卡片（模块名 + 最近更新 + 状态灯 + 引用计数）；⛔ 不出现业绩数字与业务名词。
- **承接能力块**：新增 `.ovr`。数据来自 `OS.NAV` + `grp.PLAN` + `state.js` 运行状态。

### ▇▇ 重要信息同步 · `m_notice`

- **定位**：全站最高置顶的结论与警示（跨模块汇总的一句话陈述）。
- **呈现要求**：竖排卡片列表，每张 ▇▇行：结论 + 出处（跳转到源模块）+ 时间；⛔ 不含业绩数字，数字必须替换成"变了 / 推翻 / 已旧"这类事件描述。
- **承接能力块**：聚合 `.mxsum`（本页结论）+ 各页 `.mxk` 中"事件类"条目。

### ▇▇ 今日更新动态总览 · `alert`（保留旧 id）

- **定位**：跟昨天相比，系统本身动了哪些地方：记忆库改了哪条、规则加了哪条、数据源刷新了哪张、哪些模块被点过。
- **呈现要求**：三格布局——记忆库变更 · 数据源新鲜度 · 模块动作足迹；⛔ 不再叫"异动预警"（口语化），改成"今日更新动态总览"。
- **承接能力块**：`.hqd`（本日新增）+ `.sysfr`（数据新鲜度）+ 新增"记忆库变更今日一览"（读 `memory/05-记忆变更日志.md`）。

### ▇▇ 自运行工作流进展 · `deck`（保留旧 id）

- **定位**：系统自动跑的东西现在到哪：每日 11:00 刷新是否跑过、自巡访是否触发过、待办工作流哪几件在跑。
- **呈现要求**：任务矩阵表（任务名 · 上次运行 · 状态 · 下次触发）+ 项目进度条；⛔ 不再显示今天/本周/本季业务待办数字（那些去 Ⅳ 区 ▇▇）。
- **承接能力块**：`.frsh`（每日更新时钟镜像）+ `.sysrun`（脱业务名版）+ 新增 `.runq`（自运行任务列表）。**旧的 `.bizs`（业绩关键两项）从本页下架**，迁到 ▇▇。

### ▇▇ 待反馈确认信息同步 · `m_pend`

- **定位**：全站需要她一句话就能处理的事的镜像入口：等她定的、等她补料的、可采纳的、可驳回的，都在这一格集中。
- **呈现要求**：⚑ 状态灯 + 逐条问题（问题 · 来源模块 · 最快回应方式）；⛔ 不出现业绩数字。
- **承接能力块**：镜像 `.mxask`（待裁决）+ `.pgv`（待补充）+ `FB` 未读。

### ▇▇ 系统自运行优化建议 · `advice`（保留旧 id）

- **定位**：系统自查后推出的<b>驾驶舱层</b>建议（非业务）："哪个模块最近 ▇▇ 天没被点、建议下架""哪条自运行任务失败率高"。
- **呈现要求**：卡片流（建议 + 采纳/驳回按钮 + 驳回原因输入）；⛔ 不放业务建议（业务建议去 Ⅳ 区 ▇▇）。
- **承接能力块**：抽 `[data-mod=m-advice]` 里"系统类"条目 + `.recmap` 里驾驶舱层部分。

### ▇▇ 此模块优化反馈 · `fb_ov`

- **定位**：驾驶舱区专属反馈入口。
- **呈现要求**：一张 FB.noteBox，`scope=zone:ov`；⛔ 只收针对本区的意见。
- **承接能力块**：复用 `fb.js`，加 zone tag。

## Ⅱ 认知与学习（▇▇ 模块）

### ▇▇ 记忆库总目录总览 · `memory`（保留旧 id）

- **定位**：五册记忆 + 系统认知 + 系统调度 + 业务模块的分层总目录；每册最近版本、行数、云端镜像状态。
- **呈现要求**：树形分册表 + 昨日新增行；⛔ 不复述具体规则条文（那些去 ▇▇），只展示"记在哪、几时记的"。
- **承接能力块**：`.cat` 整体。

### ▇▇ 外部思维原料与采纳建议 · `m_ext`

- **定位**：本区的核心增量。外部书籍摘要 · 媒体资料 · 平台白皮书 · 跨业务案例，每条给一句"我从这里学到什么、建议采纳为规则/口径/打法/否决线"。
- **呈现要求**：投喂通道（URL/截图/PDF）+ 摘要卡 + 采纳建议 tag（成规则/成机会/存疑/归档）；⛔ 不放具体业绩数字，⛔ 不复述已在记忆库里的内容。
- **承接能力块**：新增 `.ext`。

### ▇▇ 今日记忆库更新动态 · `m_chg`

- **定位**：今天记忆库改了哪条：新增 · 修订 · 降级 · 归档。
- **呈现要求**：时间轴（时间 · 记忆册 · 动作 · 摘要 · diff 链接）；⛔ 不推翻结论（推翻走 ▇▇），只做流水。
- **承接能力块**：直读 `memory/05-记忆变更日志.md`。

### ▇▇ 用户每日思维模式动态 · `pattern`（保留旧 id）

- **定位**：她自己今天的思维模式提示。
- **呈现要求**：她的最近一次决策风格 + 最近偏好漂移 + 最容易犯的错的今日提醒；⛔ 不出现业务结论。
- **承接能力块**：`.pat` + pattern 页原 `.mxk`。

### ▇▇ 待反馈确认信息及纠错同步 · `premise`（保留旧 id）

- **定位**：被推翻的前提、降级为待验证的判断、她认下的判错；等她二次拍板的规则条。
- **呈现要求**：三栏表（可信 → 可疑 → 已推翻）+ 每条附事件锚 + 一键"清一下待复核队列"入口。
- **承接能力块**：`.pchk` + 原 premise 页 `.mxk` + `.rul` 里"待认领"部分。

### ▇▇ 学习认知自运行优化建议 · `m_lrn`

- **定位**：系统自查认知层的短板。"我最近哪条规则可能过期""哪个概念定义不一致""哪些结论缺 L2 市场佐证"。
- **呈现要求**：与 ▇▇ 平行但只做认知层；⛔ 不给业务改法。
- **承接能力块**：抽 `[m-advice]` 里"认知类" + `.recno` 里认知层。

### ▇▇ 新灵感捕捉与可采纳方向 · `quick`（保留旧 id）

- **定位**：她在指令栏 idea 模式或拜访路上的速记 → 系统归类 → 给可采纳方向。
- **呈现要求**：即时速记框 + 已归档速记流（每条附系统归类 + 采纳按钮）；⛔ 不再放"常用入口"（那些去 ▇▇），只做灵感。
- **承接能力块**：`[data-mod=m-inbox]` + `.spk`。

### ▇▇ 此模块优化反馈 · `fb_mind`

- **定位**：认知与学习区专属反馈入口。
- **呈现要求**：`scope=zone:mind`。

## Ⅲ 高阶交互系统（▇▇ 模块）

### ▇▇ 工作台多模块调度能力总览 · `state`（保留旧 id）

- **定位**：五环连通链路（哪些模块真互相连着）+ 协作段（模块间怎么协作）+ 数据流向 + 调度方式与能力范围说明。
- **呈现要求**：模块关系图 + 五环链路表 + 数据流动堵点；⛔ 不出现业务名词（客户/达人/机构）。
- **承接能力块**：`.sysrun`+`.sysflow`+`.netnow`+`.netcan`+`.netsame`+`.netgap`+`.cpseg--▇▇`+`.cpseg--▇▇`。

### ▇▇ 系统自运行现状与决策追踪反馈 · `confirm`（保留旧 id）

- **定位**：系统自己在跑什么、跑成什么样、跑完的结果谁看：已定事项台账、自行推进事项、未照字面执行说明、逐条放行台。
- **呈现要求**：四栏（已定 · 正在跑 · 待放行 · 未照字面执行），每条带跳转到源模块；⛔ 不放业务决策原文，只放"决策 → 结果"的元数据。
- **承接能力块**：`.dnl`+`.dvi`+`.ownmine`+`.ownask`+`.ownstop`+`.gate`+`.pgp`。

### ▇▇ 底层可调用进阶能力技能库 · `call`（保留旧 id）

- **定位**：能力商店（▇▇ 装/▇▇ 停/▇▇ 精选/▇▇ 高热）+ 高阶指令库 + 潜力协作机会（未装但可装）—— 一句话调用即可复制发送。
- **呈现要求**：能力商店卡片流 + 指令列表 + 潜力协作机会区；⛔ 不放业务结论，只做能力目录。
- **承接能力块**：`.hub`+`.mxcmd`+`.cpseg--▇▇`。

### ▇▇ 系统体检与优化提案建议 · `cap`（保留旧 id）

- **定位**：系统自己出的体检结论 + 定向推荐能力补齐 + 不建议引入清单 + 前置追问三题。
- **呈现要求**：能力商店已下架（09-23 22:50 起搬到 ▇▇），本页只留缺口 + 改法 + 前置追问。
- **承接能力块**：`.recmap`+`.recno`+`.recgrill`+cap 页 `.mxk`。

### ▇▇ 此模块优化反馈 · `fb_sys`

- **定位**：高阶交互系统区专属反馈入口。
- **呈现要求**：`scope=zone:sys`。

## Ⅳ 业务工作区（▇▇ 模块）

### ▇▇ 外部盘面与情报 · `eco`（保留旧 id）

- **定位**：外部动态 · 动态机会挖掘 · 可拓机会 · <b>四赛道固定模块</b>（电商产业带 / 本地团购 / 渠道代理 / 短剧明星）· 主动建议 · 暂不可执行 · 数据截止。
- **呈现要求**：每条外部动态必须带出处 + 时间 + 数据截止；四赛道模块永久固定，即使当期无更新也要写"抓不到 · 明写"，⛔ 不许无声删除（R-623）。
- **承接能力块**：`.eco__sec--facts / dig / opp / tracks / avoid / fr` + `.spk`。

### ▇▇ 目标与业绩达成 · `base`（保留旧 id）

- **定位**：季度业绩总览 · 分层与专项达成情况 · 经营总判断 · 策略动作 · 主动建议 · 剩余缺口 · 待结算池。
- **呈现要求**：<b>业务助力自主判断</b> —— 先做"当前达成怎么样、卡在哪儿、下一步该做什么"三段结论，再列数字；数字必须过口径对照，⛔ 不许手抄；驾驶舱下架的 `.bizs`（缺口 + 待结算两项）落在页头。
- **承接能力块**：`.mxsum`+`.mxk`+`.viz`+`.bzv`+`[m-bizmoves]`+`.bizs`+`.hqn--sup`+`.hqn--need`。

### ▇▇ 客户与商机需求 · `cust`（保留旧 id）

- **定位**：开放商机 · 可提报与缺表 · 点名类 · 明星类 · 客户诉求变化 · 授权类需求。
- **呈现要求**：<b>业务助力</b> —— 页头给出"今天先做哪几件、为什么"三条；⛔ 客户零散诉求不能当趋势，要叠加大盘同行业投放趋势才报预警（R-621 沿用）。
- **承接能力块**：`.hqn--need`+`[bzsec-cust]`。

### ▇▇ 周度策略回顾 · `run`（保留旧 id · 含作战执行与节奏）

- **定位**：本周策略回顾五板块 · 每周二复盘 · 拜访快记 · 已入档拜访纪要 · Q4 短剧名单等专项。
- **呈现要求**：五格标题别名保留 —— 周度复盘总结 / 本周策略回顾 / 拜访策略回顾记忆（09-18 例外白名单）；每周二一篇复盘，先读底仓再写。
- **承接能力块**：`.rv`+`.wk`+`.vst`+`.vlog`+`.q4dr`。

### ▇▇ 策略资料库 · `plays`（保留旧 id · 含打法案例与对客材料 + 原 supply 策略资料）

- **定位**：可复用打法（角色/能力域/模式/宏观信号）· 高变现能力拆解 · 案例分析工作台 · 机构策略资料库 ▇▇块 · 策略证据链。
- **呈现要求**：<b>案例分析工作台仅参考视频，⛔ 不采信任何数字</b>（R-619/▇▇ 沿用）；供给策略 ▇▇块 09-18 已入库，与打法合流。
- **承接能力块**：`.pl--role/dom/mode/sig/cant`+`.cext`+`.extks`+`[spl-*]` × ▇▇ +`[m-bizevd]`。

### ▇▇ 底仓数据能力 · `m_data`

- **定位**：用于工作台所有分析调用来源。常用看板入口 · 每日更新时钟 · 业绩看板总览 · 数据底仓 · 数据口径对照 · 每日刷新规则 · IDA 日报动态业绩看板。
- **呈现要求**：入口卡片流（缩略图 + 用途 + 数据截止 + 直达）；⛔ 页面不呈现具体业绩数字（那些去 ▇▇），只做入口与规则；11:00 刷新规则明写在此。
- **承接能力块**：`.frsh`+`.mxlnk`+`#bzboards`+`#bzsrc`+`[m-bizcal]`+`[m-daily]`+IDA 看板卡片。

### ▇▇ 自运行工作处理情况与反馈 · `m_brun`

- **定位**：<b>本区的核心增量</b>。业务助力今天替她跑了哪几件业务动作 + 每件的思考反馈与优化建议。
- **呈现要求**：动作流（时间 · 动作 · 结果 · 反馈 · 优化建议），每条附来源模块跳转；这一模块回答"你今天干了什么、下一步打算怎么办、需要我什么"。
- **承接能力块**：新增 `.bizrun`。

### ▇▇ 此模块优化反馈 · `fb_biz`

- **定位**：业务工作区专属反馈入口。
- **呈现要求**：`scope=zone:biz`。
