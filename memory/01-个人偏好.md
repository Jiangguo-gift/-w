## U-28 · 她验收「灵感库」的固定方式：丢一份外部素材，看我能不能提炼出「能接在她框架上」的方向

**她的原话**（2026-09-16，补在灵感库板块）：
> 「我上一次补入了一份灵感来源的信息，**后面可以这么对你验收动作**」
> 「我给你分享一份大家日常分享的一些 skill 内容，请你看看**有没有比较好的操作技巧，或者比较实用的策略，可以在我的框架上做延展结合的**，给我**几个建议方向**」

**这句话真正定的是什么**：不是让我读一份文档，而是**把「投喂外部素材 → 我回可嫁接方向」立成一个可反复调用的验收动作**。
她验的不是我读得全不全，是**我能不能把别人的东西接到她已经有的那套东西上**。

**因此我的回法必须满足**：
▇▇. 交付物是**方向**，不是素材摘要。她要的是「几个建议方向」，不是「这份文档讲了什么」。
▇▇. 每条方向必须**点名接到她框架里的哪一块**（放行台第几件 / 复盘第几段 / 哪一页 / 哪条已定规则）。接不到具体位置的，不算方向，只算资讯 —— 不许端上去。
▇▇. 允许并且鼓励出现「**别造，直接接别人的**」这种结论。她的时间比功能值钱，劝我别做也是交付。
▇▇. 数量 **▇▇~▇▇条，宁少不凑**；如果这份素材里确实没有能接的，就写「这份没有能接的」并说明为什么 —— **不许为了交差硬凑**。
▇▇. 素材本身进 `_系统/灵感来源台账.md` 存档，注明她给的时间、链接、我提炼了什么、她点了哪几条、后来落地没有。

**反面**：给她一份"▇▇个 skill 分类汇总"就是没交付 —— 那是我在替她读文档，她要的是嫁接图。

## U-29 · 她说"策略不实用"时，指的不是缺动作，是**证据链太薄**——尤其缺"市场那一层"

**原话锚**（2026-09-16 22:32 / 21:40）：
> 「客户商单沟通仅仅是一些零散的需求，**不能代表客户的投放趋势**，这个信息你还是要**结合市场的趋势判断**，以及可以**从业务基本盘的底仓链接看大盘的行业投放趋势变化作为佐证信息**」
> 「目前的七条策略还是比较片面，我需要这个策略要**结合工作台的理解深度分析**，你可以**重复向我确认打磨**」

**我原来的误判**：我以为她说"看起来没那么实用"＝缺"今天下班前做什么"，所以准备给每条挂一个动作。**错了**。她两次说的都是同一件事：**我的结论只站在我自己盘里的数上**，没有回答"这是市场在变，还是我一家在波动"。

**因此以后任何写成"策略/结论"的东西，四层必须齐**：
▇▇. **L1 我自己盘的数**：至少两个独立源，写清口径 + 数据截止日。
▇▇. **L2 市场 / 大盘趋势佐证**：回答"这是趋势还是我一家的波动"。⛔ **缺这层的不许写成结论，只能叫待验证线索。**
▇▇. **L3 客户端信号**：客户原话只当线索。⛔ **单独出现时必须跟一句"零散需求，不代表投放趋势"。**
▇▇. **L4 钱从哪挣、哪个环节在漏**：答不出的，那是运营动作，不是策略。

**两条否决线**（写死）：缺 L2 → 降级；只有 L3 → 必须标注零散信号。

**还有一层她默许的做法**：「你可以重复向我确认打磨」——她**允许我为了对齐理解多问几轮**，前提是每轮都要具体到可点选（四层每层给"这层我认 / 这层要改"），不是拿抽象问题耗她。

## U-30 · 凡是我说"每日更新"的东西，她要看到**更新节奏本身**，不许拿旧内容假装今天的

**原话锚**（2026-09-16 21:50，对生态盘面）：
> 「这里的市场分析资讯等等的要做到**每日更新**，并**结合业务基本盘数据实现动态机会挖掘**，你可以设置一个**可采纳的选项**，这个选项后续可以**纳入协作机制与调用思考的策略信息输入**」

**这句话里有三件事，缺一件都算没做**：
▇▇. **每日更新**：页面必须明写「多久更一次 / 上次是哪天 / 这次更了什么 / 没跑成怎么办」。⚠️ 我不是常驻进程，所以宁可写"沿用 X 月 X 日、已旧 N 天"，也不许让旧内容顶着今天的日期。
▇▇. **动态机会挖掘**：外部资讯**必须和她的业务基本盘做交叉**才算机会——单纯的行业新闻是资讯，不是机会。交叉规则要固定、可复算（我在涨 × 大盘有缺口 / 我为 ▇▇ × 大盘在涨 / 大盘出新玩法 × 我有现成名单 / 客户在问 × 我答不上来）。
▇▇. **可采纳**：每条机会要能被她一键采纳，**并且采纳之后要真的去某个地方生效**（复盘取数方向 / 策略证据链的 L2 候选 / 拜访情报包 / 灵感库方向池）。做不到的去处要在页面上写明做不到——⛔ 不许用"已纳入思考"这种听起来生效、实际什么都没变的话糊过去。

**读法**：她要的不是一个资讯板块，是**一条"外部信息 → 她点头 → 进我的判断"的可见管道**。
